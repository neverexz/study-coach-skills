# Adaptive Practice

Practice targets an ability and produces trustworthy feedback. Keep the question,
supported key, learner answer, assistance and review consequence together.

## Build or resume practice

Read selected material and existing mistakes before writing new questions. For a
new set, choose coverage by objective, format and difficulty; balance weak areas
with a few earlier skills. State the coverage briefly when it helps the learner.
Resume pending questions rather than silently replacing them.

For each question establish an objective, wording, source locator/version when
source-based, verified answer/rubric, explanation and assistance status. Inspect
original figures and tables before constructing a visual key. A supported transfer
exercise is your new example, not a quotation from the source.

Read the shared [evidence rules](../learning-progress/references/evidence-rules.md)
before grading, awarding mastery, reviewing or repairing an assessment. If absent,
grade only what is justified locally and keep broader mastery provisional.

| Mode | Deliver |
| --- | --- |
| Interactive practice | One question by default; a requested batch of 2–4 separately answerable items |
| Explicit mock exam/set | Requested coverage and count, with clear sections and keys withheld |
| Review | Due or mistaken abilities, with fresh supported examples |
| Key challenge | Inspect and repair the existing question before assigning more work |

Keep keys and explanations off learner-facing output until they answer or ask for
the worked solution. Multiple-choice distractors represent plausible mistakes and
match in specificity; avoid answer clues from length, ordering or wording.
If the requested count cannot be supported, report the actual count and gap.

## Grade and adapt

Judge the actual response against the supported key/rubric, accepting equivalent
correct solutions. Return `correct`, `partial`, `incorrect` or `ungraded` with what
is right, the consequential gap and a useful next action. Resolve ambiguity with a
focused clarification. Confidence is not a substitute for source evidence.

For a batch, grade only submitted answers, retain unanswered siblings and avoid
asking for the same answer twice. Track recall ratings separately from correctness.
A shown or assisted answer contributes practice, not independent mastery.

If the learner challenges a key, inspect the original question, source and saved
answer. Void a defective record or append a corrected assessment linked to it.
Recompute dependent mastery, mistake records and review penalties. A corrected
assessment is the same response, not an extra independent success.

Example: key `2 + 2 = 5` wrongly failed the learner's `4`. Correct/regrade it,
remove its false error and penalty, and keep unanswered `8 / 2` open. The learner
need not retake the defective question or restart the batch.

## Keep progress useful

Use [learning-progress](../learning-progress/SKILL.md) for saved work and its review
heuristic. Record actual IDs and changes, then verify writes. Without that sibling
or file access, provide a labelled correction/handoff summary instead of a save claim.
Offer a pause or a fresh targeted example after feedback; avoid grinding the same
unsupported question. Review dates organize later sessions and create no reminders.
