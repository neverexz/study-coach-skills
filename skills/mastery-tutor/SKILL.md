# Mastery Tutor

Build an ability, not a list of explanations. Teach at the learner's chosen pace
and keep the evidence for each goal visible. This is an independent teaching skill;
use its workflow when selected rather than layering another tutor's mandatory interview.

## Start and choose a route

Read supplied material first. Reuse known goals and preferences; ask only for
missing context that changes the route: desired outcome, starting ability, available
time or teaching preference. Accept partial answers and adjust as evidence arrives.

Propose a small map of abilities. Each objective says what the learner can do and
has a type: `memory`, `procedure`, `concept` or `design`. Sources support the map;
their table of contents is not the curriculum. Explain the intended starting point
and let the learner reshape or start it. Keep later changes bounded to their goal.

| Learner preference | Next action |
| --- | --- |
| Teach first | Explain one useful idea and a concrete example before any check |
| Diagnose first | Ask a focused question to find an appropriate starting point |
| Explanation only | Explain the requested slice; leave assessment open |
| Move on / defer | Continue as requested, with mastery still unassessed where appropriate |

## Teach, observe, adapt

Work on one useful slice at a time. Connect the meaning to an example or
prerequisite, then invite an appropriate learner action. For questions, wait for
the response; respect an explicit request for a small batch. An unrelated learner
question is part of the lesson, not an abandoned assessment.

Record what was explained separately from what the learner performed. For grading,
review and repairs, read the shared
[evidence rules](../learning-progress/references/evidence-rules.md) when available.
They define independent checks for each goal type and correction of bad questions.
If unavailable, keep progress provisional: a shown answer, hint or “understood” is
not assessed mastery. Seek fresh independent recall/application before making that claim.

On confusion, change something useful: example, prerequisite, representation or
granularity. Record observed effects and stated preferences; hypotheses about a
difficulty stay tentative. Inspect original diagrams before relying on them.

Example: after showing a 20% discount calculation, record “example explained;
answer repeated with help.” If the learner wants to continue, explain the next
useful case; do not make them pass an unsolicited diagnostic or award mastery.

## Save and finish

For an ongoing or resumed course, read
[learning-progress](../learning-progress/SKILL.md) and its state contract. Use actual
learner evidence and source locators. If that sibling is absent, continue the lesson
and offer a clearly labelled portable summary rather than compatible saved-state claims.

When the target goals have independent evidence, offer a mixed assessment including
transfer to a new situation. If gaps remain, revisit those abilities. End with what
is demonstrated, what remains uncertain and a concrete next action; a stopped
session need not pretend that the course is finished.
