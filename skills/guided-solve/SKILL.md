# Guided Solve

Help the learner make the next useful move at their chosen assistance level.
Keep a worked solution separate from evidence that they can solve it independently.

## Choose the next action

Read the complete statement and the learner's attempt. Use stated constraints,
units, domain and sources. Ask about a missing condition only when it changes the
solution; otherwise state a necessary assumption and its effect.

| Request | Response |
| --- | --- |
| One hint | One small actionable hint, then wait; preserve the next move for the learner |
| Check my attempt | Locate the first consequential error or confirm supported steps |
| Full solution | Give a clear worked solution and verify the result |
| Assistance level unclear | Offer a small first hint, or ask which level they want if it matters |

For example, for `3(x − 2) = 12`, a first hint is “divide both sides by 3.”
Stop there when only a hint was requested; the learner performs the next step.

## Solve and verify

For a substantial problem, use a short plan of meaningful subproblems. Work through
them and preserve concise results, assumptions and checks, not private reasoning.
A simple equation or a single hint needs no ceremonial plan.

When an approach fails, identify the obstacle before trying a different one.
Use at most two substantial replans before explaining what is unresolved and
requesting a missing condition or proposing a narrower step.

Check the answer against the original problem: substitution, dimensions, boundary
cases, an alternative derivation or actual code execution when useful and available.
Distinguish an executed check from a proposed one. Account for excluded roots,
undefined values and units. If evidence is insufficient, leave the result conditional.

A full explanation ends with the result, the verification and the reusable method.
An interactive hint ends where the learner can act. If the task relies on a
diagram, inspect the original; keep unavailable geometry assumptions explicit.

## Connect to learning

Mark hints and shown solutions as assistance. A later fresh problem can provide
independent evidence; seeing the answer cannot. When the learner wants saved
progress, use [learning-progress](../learning-progress/SKILL.md) and its shared
[evidence rules](../learning-progress/references/evidence-rules.md). If unavailable,
offer a concise handoff with problem, assistance, remaining work and next step.
Do not claim a file was saved without actually verifying the write.
